### 1.2 범위
**포함**:
- 검색 기능
- 필터링 기능
- 채용공고 조회

**제외**:

- 결제 기능

- 대규모 부하 테스트

## 2. 사이트 기능 분석

### 2.1 주요 기능 구조
```
Wanted.co.kr
├── 공통
│   ├── 헤더
│   └── 푸터
│
├── 메인 페이지 (/)
│   ├── 원티드 에이전트
│   ├── 기능별 숏컷
│   └── 캐러셀 슬라이드
│
├── 채용 리스트 페이지 (/wdlist)
│   ├── 필터
│   ├── 태그
│   └── 채용 리스트
│
├── 채용 상세 페이지 (/wd/{id})
│   ├── 채용 공고 정보
│   ├── 회사 위치 정보
│   └── 지원하기
|
├── 사용자 페이지 (/my)
│   ├── 프로필
│   ├── 내 활동
│   ├── 게시글
│   ├── 설정
│   └── 로그아웃
|
├── 검색 페이지 (/search?query={keyword})
    ├── 검색어 탭
    ├── 검색결과
    └── 필터링


```

### 2.2 URL 패턴
- 메인: `https://www.wanted.co.kr/`
- 검색: `https://www.wanted.co.kr/search?query={keyword}`
- 채용 리스트 : `https://www.wanted.co.kr/wdlist?query={keyword}`
- 채용 상세 페이지: `https://www.wanted.co.kr/wd/{job_id}`
- 사용자 페이지 : `https://www.wanted/co/kr/my`

## 4. 테스트 전략

### 4.1 자동화 기준
**자동화 대상**:
- 반복적이고 안정적인 기능
- 명확한 검증 기준
- 회귀 테스트 필요
- 데이터 기반 검증

**수동 테스트 대상**:
- 시각적 검증 필요
- 사용자 경험 평가
- 탐색적 테스트
- 변경이 잦은 기능

### 4.2 우선순위

| 우선순위 | 영역 | 케이스 수 |
|---------|------|----------|
| **P0 (Critical)** | 검색, 필터 | 8개 |
| **P1 (High)** | 공고 상세, 정렬 | 14개 |
| **P2 (Medium)** | UI/UX, 네비게이션 | 8개 |
